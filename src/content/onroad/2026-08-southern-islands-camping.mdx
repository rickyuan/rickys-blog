> ⛺ 拉扎鲁斯岛是新加坡露营的天花板:C 形白沙泻湖、没有商店没有车,晚上正对 CBD 天际线灯光。**岛上没有任何补给(水、食物全自带)**,这份计划按一家三口 + 自带充气皮划艇设计。三岛用一张渡轮往返票串起来:圣约翰上岛 → 堤道步行到拉扎鲁斯 → 回程顺路跳岛龟屿。

## 📋 出发前清单

**露营** ⛺
- [ ] 帐篷(配沙地钉/沙袋固定)、防潮垫、薄睡袋或毯子
- [ ] **饮用水 12–15L**(岛上无水源,按每人每天 4L 算)
- [ ] 保温箱 + 冰袋:两天的熟食、水果、早餐
- [ ] 便携气炉(可选,禁明火)、头灯 ×3、大号垃圾袋

**皮划艇** 🛶
- [ ] 充气艇 + 打气泵 + 桨(码头托运前放气打包)
- [ ] **救生衣 ×3(必须)**、防水袋、拖艇绳
- [ ] 出发前查 NEA 天气(雷暴预警就取消下水)和潮汐表

**通用**
- [ ] 折叠拖车(堤道搬运装备的 MVP)
- [ ] 防晒霜、防蚊液、急救小包、充电宝 ×2
- [ ] 现金 + 交通卡;渡轮班次截图存手机

## ⚠️ 安全与规则

- 泻湖**没有救生员**,娃下水大人全程盯;皮划艇不出泻湖口、不靠近渡轮航道
- 雷暴是新加坡海上活动第一风险:听到雷声立即上岸收桨
- 圣约翰岛猴子会开背包拉链,食物锁进保温箱
- 露营无需许可,但**垃圾必须全部带走**,别给下一家留麻烦
